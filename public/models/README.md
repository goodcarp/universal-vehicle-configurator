# Model asset gate

No GLB is bundled in Item 3.

The strongest timeboxed SUV candidate was explicitly downloadable under CC BY 4.0,
but its official file endpoint required an authenticated Sketchfab session. The team
did not scrape viewer files or bypass that gate, so topology and material isolation
could not be verified. The approved runtime source is the authored 2.5D safety pack
under `public/images/` until a downloaded model clears the full asset audit.
