# Universal Vehicle Configurator

An unofficial WebMCP Challenge concept: a manufacturer-grade R2-inspired vehicle configurator with buyer-grade intelligence.

## Local development

```sh
pnpm install
pnpm dev
```

## Verification

```sh
pnpm lint
pnpm typecheck
pnpm test:run
pnpm build
```

The manual shell remains usable when `document.modelContext` is unavailable. In the latest ChatGPT desktop built-in browser, the temporary `inspect_configurator_shell` Site Tool proves the top-level imperative registration seam; it is replaced by the final twelve-tool registry later in the build.

This is an unofficial concept and is not affiliated with Rivian.
