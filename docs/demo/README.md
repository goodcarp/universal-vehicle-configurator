# Demo captures

`range-reality-gate-a.webp` is the 1280×720 visual-gate recording for the
authored 2.5D Range Reality prototype. It was verified in the supported built-in
browser and captured at 1280×720 in local Chrome on 2026-08-31.
`range-reality-gate-a-final.png` is its completed frame,
`range-reality-gate-a-interruption.png` is the separate interruption proof, and
`range-reality-gate-a-report.json` records the measured story and snap timing.

The interaction itself remains the source of truth; these files are review and
submission-preparation artifacts.
